# typot

A minimalist typing trainer with no room for errors. Paste a text and type it paragraph by paragraph.

## Usage

Open `index.html` in a browser (or serve the folder locally) and paste text into the field. Press `Enter` to start.

- A typo or `Tab` resets the cursor to the start of the current paragraph.
- After each paragraph you get WPM and the difference from the previous one.
- Text, progress and last WPM are stored in `localStorage`.
- `Esc` clears everything and starts over.

## Stack

Single file: HTML + CSS + JS. JetBrains Mono, Gruvbox Material Dark palette.
